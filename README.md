# Collaborative Recipe Book

This project was created for students to practice Git and GitHub collaboration.

## Project Goals
- Learn Git basics
- Practice collaboration
- Use pull requests
- Resolve merge conflicts

## Contribution Steps
1. Fork the repository
2. Clone your fork
3. Create a branch
4. Add your recipe
5. Commit and push changes
6. Create a pull request

## Folder Structure

Each student has their own folder.

Example:

```text
Dominic/
└── pizza-recipe.md
```
